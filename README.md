# OnlineMarketTJ

Универсальный онлайн-маркетплейс для покупки и продажи товаров в Таджикистане.
Интерфейс полностью на таджикском языке, дизайн рассчитан в первую очередь на iPhone и Android.

## Возможности

- Каталог, категории, поиск, фильтры (цена, состояние, город, сортировка)
- Страница товара с галереей, корзина, избранное
- Регистрация и вход, роли: покупатель и продавец
- Кабинет продавца: добавление, редактирование, скрытие и удаление товаров с фото и ценами
- Оформление заказов (заказ делится по продавцам), статусы заказа, кабинет заказов для продавца
- Оплата: только наличными при получении (фиктивных платежей нет)
- Подготовка к Telegram Mini App (см. ниже)

## Публикация (GitHub Pages без Jekyll)

1. Settings → Pages → Source: **GitHub Actions**.
2. Любой push в `main` запускает `.github/workflows/pages.yml`: тест логики → сборка папки сайта → публикация.
3. Файл `.nojekyll` отключает Jekyll.

Сайт будет доступен по адресу `https://<логин>.github.io/onlinemarket-tj/`.

## Локальный запуск

```bash
python3 -m http.server 8000   # затем откройте http://localhost:8000
node tests/smoke.mjs          # тест бизнес-логики
```

## Важно: где сейчас хранятся данные

GitHub Pages даёт только статический хостинг. Поэтому сейчас (`backend: 'local'` в `js/config.js`)
аккаунты, товары и заказы хранятся **в браузере каждого пользователя** и не видны другим людям.
Это рабочий прототип со всей логикой, но для реального маркетплейса нужен сервер и база данных.
Как к ним перейти, описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Демонстрационные товары помечены значком «Намунавӣ». Отключить: `seedDemo: false` в `js/config.js`.

## Telegram Mini App

1. Сайт должен открываться по HTTPS (GitHub Pages подходит).
2. В Telegram откройте @BotFather → создайте бота → `/newapp` (или Menu Button) → укажите адрес сайта.
3. Код уже подключает `telegram-web-app.js`, раскрывает окно, красит шапку и использует кнопку «Назад» Telegram.

Проверку подлинности пользователя (`initData`) нужно делать на сервере.

## Структура

```
index.html            оболочка приложения
css/styles.css        дизайн
js/app.js             роутер, навигация
js/views/             страницы (каталог, корзина, кабинеты)
js/repo/              слой данных: local.js (браузер), api.js (будущий сервер)
js/services/          платежи, доставка, Telegram, хранилище
js/data/              категории, города, демо-товары
tests/smoke.mjs       тест логики
```
