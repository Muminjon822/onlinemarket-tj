# Архитектура и план развития

## Принцип

Весь интерфейс обращается к данным только через `repo` (`js/repo/index.js`).
Есть две реализации с одинаковым набором методов:

| Реализация | Файл | Назначение |
|---|---|---|
| `LocalRepo` | `js/repo/local.js` | данные в браузере (сейчас) |
| `ApiRepo` | `js/repo/api.js` | запросы к вашему серверу (заготовка) |

Переключение: `backend: 'api'` и `apiBaseUrl` в `js/config.js`. Страницы менять не нужно.

## Подключение базы данных

Нужен небольшой сервер (например Node.js + PostgreSQL, либо Supabase/Firebase) со следующими маршрутами
(они уже описаны в `api.js`):

| Метод | Путь | Что делает |
|---|---|---|
| POST | /auth/register, /auth/login, /auth/logout | аккаунты (хэш пароля и сессии на сервере) |
| GET/PATCH | /me | профиль; POST /me/seller — стать продавцом |
| GET | /products, /products/:id | каталог |
| GET | /seller/products | товары продавца |
| POST/PUT/PATCH/DELETE | /products[/:id] | управление товарами (только владелец) |
| POST | /orders | создать заказы (проверка остатков в транзакции) |
| GET | /orders?as=buyer\|seller | списки заказов |
| PATCH | /orders/:id | смена статуса |

Фотографии: сейчас сжимаются и хранятся в браузере. На сервере загружайте их в файловое хранилище
(S3-совместимое) и сохраняйте только ссылки в поле `images` товара.

Модель данных: `users`, `products`, `orders`, `order_items` (поля видны в `local.js`).

Что сервер обязан делать сам (нельзя доверять браузеру): проверку прав, остатки и цены в заказе, хэширование паролей, проверку Telegram `initData`.

## Оплата

`js/services/payments.js`: список способов оплаты. Сейчас только `cod` (наличные при получении).
Для онлайн-оплаты добавьте провайдера (платёжный шлюз Таджикистана: Алиф, DC Next, Visa/Mastercard через эквайринг).
Платёж должен создаваться и подтверждаться на сервере (webhook), а в заказе появится поле `paymentStatus`.

## Доставка

`js/services/delivery.js`: сейчас два способа: «таҳвил по договорённости» и «самовывоз».
Для службы доставки добавьте провайдера с расчётом стоимости и сроков (`quote(order)`),
а в заказ запишите `deliveryFee` и номер отслеживания.

## Telegram Mini App

Клиентская часть готова (`js/services/telegram.js`). Для входа через Telegram добавьте на сервере
`POST /auth/telegram`, который проверяет подпись `initData` и создаёт/находит пользователя.
